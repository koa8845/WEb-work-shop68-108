Workshop: HTML Heading

ฝึกใช้แท็ก <h1> ถึง <h6> และการจัดระเบียบเนื้อหาด้วยหัวข้อ

1. ความหมายของ Headings (H1–H6)

HTML มีแท็กสำหรับกำหนดหัวข้อทั้งหมด 6 ระดับ โดยมีลำดับความสำคัญและความหมายดังนี้ครับ:

H1 – หัวข้อใหญ่ที่สุด ใช้สำหรับชื่อเรื่องหลักหรือหัวข้อหน้าเว็บ (ควรมีเพียง 1 อันต่อหน้า)

H2 – หัวข้อรอง ใช้แบ่ง Section สำคัญของเนื้อหา

H3 – หัวข้อย่อยลงมาจาก H2

H4 – หัวข้อย่อยระดับที่ 4

H5 – หัวข้อย่อยระดับที่ 5 (ใช้งานน้อย)

H6 – หัวข้อระดับเล็กที่สุด

💡 SEO Tip: การเรียงลำดับหัวข้อจาก H1 ไป H6 ให้ถูกต้องตามโครงสร้าง จะช่วยให้โปรแกรมค้นหา (Search Engine) เข้าใจเนื้อหาเว็บไซต์ได้ดีขึ้น
2. ตัวอย่างการใช้งานจริง (H1–H6) 
<h1>Welcome to My Website</h1>
<h2>HTML Basics</h2>
<h3>What is HTML?</h3>
<h4>HTML Syntax</h4>
<h5>Example Code</h5>
<h6>Note: Case Sensitive</h6>

H1: Welcome to My Website

H2: HTML Basics

H3: What is HTML?

H4: HTML Syntax

H5: Example Code
H6: Note about heading size

Tip: คุณสามารถใช้สกุลไฟล์เป็น .htm หรือ .html ก็ได้ ไม่มีผลต่อการทำงาน เลือกใช้ตามความสะดวกได้เลยครับ

Note: แท็ก HTML บางตัวไม่มีเนื้อหาภายใน (เช่น แท็ก <br>) เราจะเรียกแท็กเหล่านี้ว่า Empty Elements ซึ่งจะไม่จำเป็นต้องมีแท็กปิดครับ
